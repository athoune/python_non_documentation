== Variables

Une valeur peut être désignée par une variable.

Les variables peuvent stocker le résultat d'une opération ou d'une fonction.

```
>>> a=42
>>> a+3
45
>>> b=1+2
>>> b
3
```

[TIP]
.ハッキング Hakkingu
--

Les variables ont une portée : une variable crée dans une fonction n'existe que dans cette fonction.
